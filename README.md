# 2026 전주대학교 대동제 & 해커톤 통합 운영 로그 분석

## 프로젝트 소개

파이썬의 `re` 모듈(정규표현식)을 이용해 전주대학교 대동제 및 해커톤 통합 운영 데이터 로그에서 이메일, 휴대폰 번호, 재학생 학번/학과, GitHub 저장소 주소, 2026년 쿠폰 코드, 부스 매출액을 추출하고 전체 매출 합계를 계산하는 프로그램입니다.

## 사용 기술

- Python 3
- Python 표준 라이브러리 `re`, `pathlib` (별도 패키지 설치 불필요)

## 프로젝트 구성

```text
regex_assignment/
├── main.py
├── README.md
└── 07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그.txt
```

## 실행 방법

1. 위 파일 3개를 같은 폴더에 둡니다.
2. VS Code 등에서 해당 폴더를 엽니다.
3. 터미널에서 아래 명령어를 실행합니다.

```bash
python main.py
```

환경에 따라 `python3 main.py` 명령어를 사용합니다. 입력 텍스트 파일은 UTF-8(또는 UTF-8 BOM)로 읽습니다.

## 기능 및 정규표현식

### 1. 유효한 이메일 추출

```regex
(?<![\w.@-])[A-Za-z0-9._%+-]+@[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)+(?![\w.-])
```

- `@` 앞에 계정 이름이 있고, `@` 뒤에는 점(`.`)으로 구분되는 도메인이 있어야 합니다.
- `hyunwoo@.ac.kr`과 같이 도메인의 시작 부분이 비어 있는 잘못된 이메일은 제외합니다.
- 로그 전체에서 찾으므로 참가자뿐 아니라 정산 문의 담당자의 이메일도 포함됩니다.

### 2. 휴대폰 번호 추출

```regex
(?<!\d)010[-. ]\d{4}[-. ]\d{4}(?!\d)
```

- `010`으로 시작하고, 중간 4자리와 끝 4자리로 구성된 번호만 추출합니다.
- 하이픈(`-`), 점(`.`), 공백을 구분자로 허용합니다.
- 지역번호 `02`, `063` 등의 일반전화와 자릿수가 부족한 번호는 제외합니다.

### 3. 본교 재학생 학번/학과 추출

```regex
\[\s*(202\d{6})\s*/\s*([^\]\r\n]+?)\s*\]
```

- `[학번 / 학과]` 형식에서 `202`로 시작하는 9자리 학번을 찾습니다.
- `re.findall()`의 캡처 그룹을 사용해 `(학번, 학과)` 튜플로 추출합니다.
- 외부인 학번과 8자리 학번은 제외합니다.

### 4. GitHub 저장소 및 2026년 쿠폰 추출

GitHub 저장소 URL:

```regex
https?://github\.com/[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+(?:\.git)?(?=$|[\s)\]])
```

- `github.com`의 사용자/저장소 형태 주소를 추출합니다.
- `http`와 `https`를 허용하고 `.git`으로 끝나는 주소도 포함합니다.
- `gitlab.com` 주소는 제외합니다.

2026년 쿠폰 코드:

```regex
(?<![A-Za-z0-9-])FEST-2026-[A-Z0-9]{4}(?![A-Za-z0-9-])
```

- `FEST-2026-` 다음에 영문 대문자 또는 숫자 4개가 나오는 코드만 추출합니다.
- `FEST-2025-OLD9` 등 다른 연도의 코드는 제외합니다.

### 5. 부스 매출액 추출 및 합산

```regex
^\s*-\s*(.+?)\s+매출:\s*([\d,]+)원
```

- `re.MULTILINE` 옵션을 사용해 각 줄에서 `매출:` 직후의 금액만 추출합니다.
- 카드/현금 세부 내역 및 할인 쿠폰 금액은 계산에 포함하지 않습니다.
- 쉼표를 제거한 뒤 `int`로 변환하여 전체 합계를 계산합니다.
